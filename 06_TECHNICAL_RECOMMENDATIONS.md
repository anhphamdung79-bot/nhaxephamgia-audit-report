# Technical Recommendations

## 1. Immediate Technical Actions
- Compress all homepage media assets to WebP or compressed JPEG.
- Add `width` and `height` to images.
- Add `loading="lazy"` to below-the-fold images.
- Remove unused CSS/JS references.
- Review all CTA buttons for contrast and keyboard focus.

## 2. SEO Implementation
- Add one H1 only per page.
- Improve title tag length and keyword placement.
- Rewrite meta descriptions with CTA and benefits.
- Add schema with Organization / LocalBusiness / Breadcrumb.

## 3. Accessibility Implementation
- Use semantic HTML (`header`, `main`, `nav`, `footer`, `button`, `form`).
- Ensure visible focus styles.
- Add `aria-label` only when needed.
- Ensure form inputs have associated labels.

## 4. Performance Implementation
- Serve responsive images by viewport size.
- Minify and defer non-critical JS.
- Inline critical CSS when needed.
- Use an efficient CDN and browser cache policy.

## 5. Quality Assurance Checks
- Test on mobile Safari and Chrome.
- Run Lighthouse on desktop and mobile.
- Run WAVE and axe DevTools for accessibility.
- Validate structure in browser dev tools.

## 6. Final Conclusion
Website có thể cải thiện mạnh nếu ưu tiên vào các vấn đề cốt lõi: hình ảnh, mobile performance, accessibility và SEO cơ bản. Đây là chiến lược hiệu quả để tăng trải nghiệm và tỷ lệ chuyển đổi trong thời gian ngắn.

# Customer Ready Report

This folder contains a polished customer-facing report and a print-friendly HTML version for PDF export.

## Files
- `CUSTOMER_REPORT.md` — polished markdown report for email / GitHub / sharing
- `customer-report.html` — print-friendly version ready to export to PDF via browser

## How to export to PDF
1. Open `customer-report.html` in a browser
2. Press `Ctrl/Cmd + P`
3. Choose `Save as PDF`
4. Set margins to `Default` or `Minimal`
5. Save the file

## Note
The HTML version is designed for clean printing and presentation to clients or stakeholders.

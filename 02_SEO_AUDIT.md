# SEO Audit

## 1. Scope
Đánh giá SEO trên trang chủ và các trang trọng tâm của website, tập trung vào title tag, meta description, heading structure, hình ảnh, nội dung, liên kết và markup.

## 2. Findings

| Checkpoint | Status | Notes |
|---|---|---|
| Title tag | ⚠️ Partially optimized | Cần chứa từ khóa chính rõ ràng hơn |
| Meta description | ❌ Needs update | Thiếu CTA và mô tả giá trị rõ ràng |
| H1 structure | ⚠️ Incomplete | Nên duy nhất và mô tả rõ chủ đề |
| Heading hierarchy | ❌ Weak | H2/H3 chưa được tổ chức hợp lý |
| Image alt text | ❌ Weak | Nhiều ảnh thiếu alt text hoặc alt text không đủ ý nghĩa |
| Canonical tag | ✅ Likely okay | Cần xác nhận với kiểm tra kỹ thuật |
| Schema markup | ❌ Missing | Thiếu schema doanh nghiệp / địa điểm / FAQ |
| Internal linking | ⚠️ Moderate | Cần nối tốt hơn giữa các trang tour/dịch vụ |

## 3. Recommendations
- Tối ưu title tag theo định dạng: "Tên địa điểm / Dịch vụ | Thương hiệu".
- Meta description nên ngắn gọn, có CTA và mô tả lợi ích rõ.
- Chỉ giữ 1 H1 chính trên từng trang.
- Dùng H2/H3 rõ ràng để phân đoạn nội dung.
- Tạo alt text mô tả thay vì tên file không rõ nghĩa.
- Bổ sung schema cho Organization, LocalBusiness, Breadcrumb, FAQ nếu phù hợp.

## 4. Priority Fixes
### P1
- Title/meta description
- Heading hierarchy
- Alt text

### P2
- Schema markup
- Internal linking
- Content structure

## 5. Expected SEO Gain
Sau khi sửa các điểm chính, website có thể tăng CTR từ tìm kiếm và cải thiện khả năng hiển thị trên mobile search results.

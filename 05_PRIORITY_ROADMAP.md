# Priority Roadmap

## 1. Objective
Xác định trọng tâm và thứ tự ưu tiên để tối ưu hiệu quả nhanh nhất với nguồn lực hợp lý.

## 2. Timeline

| Phase | Duration | Focus | Expected Result |
|---|---|---|---|
| Phase 1 | 1-2 weeks | Image optimization + meta fix + keyboard access | +1.5 score |
| Phase 2 | 2-3 weeks | Heading structure + contrast + form labels | +1.2 score |
| Phase 3 | 3-4 weeks | Schema + CSS/JS optimization + caching | +0.7 score |

## 3. Phased Action Plan
### Phase 1
- Nén hình ảnh và điều chỉnh banner
- Chỉnh sửa title/meta description
- Thêm alt text theo nhóm hình ảnh
- Fix keyboard nav và focus state

### Phase 2
- Chỉnh sửa heading hierarchy
- Tăng contrast, sửa button/CTA
- Cập nhật label form và thông báo lỗi

### Phase 3
- Thêm structured data
- Tối ưu JS/CSS
- Review cache, compression và resource load

## 4. Success Criteria
- LCP dưới 2.5s
- CLS dưới 0.1
- Accessibility score >= 90
- SEO score >= 9/10
- Mobile speed score >= 90/100

## 3. Recommended Priority

### P1 - Phải ưu tiên ngay
- Nén hình ảnh và tối ưu banner/slider
- Cải thiện title/meta description
- Chữa lỗi heading hierarchy
- Thêm alt text cho hình ảnh quan trọng
- Fix keyboard navigation và focus state
- Cải thiện contrast cho text và CTA

### P2 - Ưu tiên trong vòng 2-3 tuần
- Thêm schema markup cho doanh nghiệp
- Chỉnh sửa form labels và thông báo lỗi
- Tối ưu lazy loading và preload resource
- Giảm JS/CSS nặng

### P3 - Tối ưu dài hạn
- Tăng tốc CDN/cache policy
- Tối ưu font và resource loading
- Áp dụng tối ưu mobile-first toàn diện
